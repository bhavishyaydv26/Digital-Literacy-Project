## 🗂️ Module Summaries

### Task 1 – Digital Literacy Infographic (Module 1)
Created a one-page infographic using **Canva** covering: what digital literacy is, useful digital tools for students, safe internet practices, and professional online presence. The visual was designed to be shared with batchmates as a Student Digital Ambassador resource.

### Task 2 – Student Digital Portfolio (Module 2)
Set up professional profiles on **GitHub**, **LinkedIn**, and **Kaggle**. Created a GitHub Profile README highlighting name, branch, year, and learning goals. Filled in Education section on LinkedIn with current degree details.

### Task 3 – Coding & Collaboration Platforms (Module 3)
Completed a beginner challenge on **HackerRank** (Python Introduction). Built a **Google Form** with 5 questions as a Digital Literacy Awareness Quiz for batchmates, linked to a Google Sheet for response tracking.

### Task 4 – Email Etiquette & Social Media Guide (Module 4)
Drafted two professional emails — one requesting an assignment extension from a professor, and one expressing internship interest to a company coordinator. Also created a Social Media Do's and Don'ts checklist with 10+ items.

### Task 5 – Cybercrime Awareness (Module 5)
Researched **UPI/Online Payment Fraud** — wrote a 200–250 word case study and created a 'Stay Safe Online' prevention checklist with 8+ actionable tips tailored for Indian college students, including UPI-specific safety measures and reporting channels.
